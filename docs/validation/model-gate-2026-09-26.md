# September 26 model-selection gate

Decision: retain the existing local detector and deployed policy for the simulated demonstration. Defer detector replacement and any threshold change. This is an engineering fallback, **not** a claim that the frozen detection targets passed.

The only scored corpus currently available in `models/evaluation/manifest.csv` is the historical 40-clip English regression set. It has seven manifest columns, no Hindi, Indian English, Hinglish or Marathi slices, no confirmed held-out generator family, and an already-viewed test split. The [Stage 0 receipt](stage0-2026-09-24.md) reports validation HIGH recall 6/10 scorable synthetic clips and false HIGH blocks 1/7 scorable genuine clips at the deployed 0.75 threshold. Both miss the [predeclared target](../evaluation-protocol.md). Its alternative threshold was exploratory and is not deployed. The [M04 public-clip probe](m04-public-probe-2026-09-24.md) also shows a known synthetic miss under simulated noise/band-limiting; two clips cannot justify retuning.

The local `models/spoof_detector.onnx` SHA256 on this date is `7af799e8443c3d030bb3ef644ffc6e74f5b6fddcd6a4286ee9abe9e828cb762e`; application defaults remain `HIGH_RISK_SPOOF_THRESHOLD=0.75`, `THRESHOLD_PROFILE=prototype-uncalibrated-v1`, and the runtime profile digest recorded by Stage 0 is `prototype-uncalibrated-v1:9535b80951b0`. No model, preprocessing, smoothing, quality gate, cadence, evidence TTL, or action authorization code is changed by this decision.

Missing dependency: rights-cleared, source/speaker/generator-disjoint four-language genuine and synthetic recordings with lineage, consent/license and an untouched test partition. Without them, Stage 1 training, representative threshold selection, and a one-time final test cannot meet the protocol. M03 stays blocked; the current model is a prototype demonstration component, not a validated detector for financial deployment. LOW or ELEVATED is not identity proof, and every completed action still requires valid action-bound verification. HIGH or unavailable evidence still blocks.

Resume the model track only after D02's manifest passes the split/leakage validator and the permitted validation corpus can be scored. Select any candidate/threshold on validation, freeze all inference and policy inputs with hashes, then run the untouched final test once. If it fails, report failure and do not retune against it.
