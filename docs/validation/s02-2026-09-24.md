The wire contract is now `pcm16-seq-v1`: authenticated handshake followed by little-endian uint32 frame sequence plus exactly 6,400 bytes of 16 kHz mono PCM16 per 200 ms. Legacy unsequenced binary is deliberately rejected because it cannot establish order/freshness for protected-action evidence. The route and token contract remain unchanged. The browser closes rather than accumulating an unbounded send backlog. Reused detector scores may update the display but do not renew database evidence. HIGH evidence, replacement and disconnect block unfinished actions with audit; startup invalidates interrupted live actions. The action gate also checks the current single-process stream registry, preventing a failed disconnect-audit transaction from leaving a stale LIVE row usable.

Limits: the 600-second input repeated one local demo WAV at real-time pacing; it was not a physical microphone, multi-user load or a representative attack distribution. The final source had a 30-second stream confirmation, not a repeated ten-minute run. Chrome used a fake input device. No real Jev call, four-language corpus, untouched final model test, 10-second WAV p95 or production minimum-hardware claim is established. The isolated validation records remain in the test database; no existing demo records or volumes were reset.
