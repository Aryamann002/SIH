# L01: local Laya shadow migration (2026-09-28)

## Decision and source

Jev is no longer called by new actions. The optional Laya sidecar receives only the existing structured evidence buckets after the deterministic hard gate; it cannot approve a transfer or bypass action-bound verification. `LAYA_MODE=shadow` remains the only presentation-approved mode, and `LAYA_ENABLED=false` is the default. The active local backend was explicitly started with `LAYA_ENABLED=true`; the sidecar is running from cached weights with `HF_HUB_OFFLINE=1`. This is a development checkout, not a frozen release.

Upstream [Laya code](https://github.com/NandhaKishorM/laya/tree/9d955671415fc19f069b9cc998928075c1f255ec) is pinned to `9d955671415fc19f069b9cc998928075c1f255ec`; its [English checkpoint](https://huggingface.co/convaiinnovations/laya/tree/55cf4c4ebb4ebe31b2550e8bdf3bd21b99753851) is pinned to `55cf4c4ebb4ebe31b2550e8bdf3bd21b99753851`. The cached `model.safetensors` SHA256 is `891102d372688fc2a094dac56a384bc537b87c63f21f9f3dac0be2b7cbc8d86c`. Local image IDs: backend `sha256:76da2d773d40211451876c653c044deb042cbf1e95408aabc46efeb5d8d83aa5`; sidecar `sha256:1cb195cc18735d9b1dcd408c99896194ec543aba89f8cd5d669f3f8f9dc0d80a`. ## Remaining limits

Laya's base checkpoint has published zero-shot decision limitations; one local run warned that some checkpoint choice temperatures were clamped. Treat its confidence and probabilities as uncalibrated. No VigilVoice-labeled shadow agreement, unsafe-downgrade estimate, calibration, representative language test, or sustained concurrency benchmark exists. Advisory remains gated off. The final source package, PDF/video render and physical presentation rehearsal must be refreshed after this change. Historical Jev audit rows are retained; no keys, OTPs or private audio were migrated or logged.
