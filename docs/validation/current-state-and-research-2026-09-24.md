## Actual serving path

| Area | Source-bound observation | Limit or unverified point |
|---|---|---|
| Capture and transport | `app/static/{microphone,pcm-worklet}.js` requests a mono 16 kHz context with browser echo cancellation, noise suppression and gain control off; the worklet sends 3,200 PCM16LE samples/6,400 bytes every 200 ms. The browser sends a bearer token as first JSON WebSocket frame to `/api/v1/stream/ws/{session_id}` and receives `ready` then one result per binary frame. | There is no sequence number, producer timestamp or bounded browser/WebSocket send queue. The server accepts any even-length frame through 16,000 bytes and times out reads after five seconds. Network backlog can make old audio look current. Physical-device cadence is not measured. |
| Admission and inference | One active audio session and one CPU inference worker; queue wait 1 s and inference wait 10 s. A timed-out native inference retains the slot until completion. | One-stream capacity is intentional; 10-minute backlog and warm latency need measurements. |
| VAD and quality | `AudioPipeline` uses Silero v5.1 ONNX at 16 kHz, 512-sample frames with recurrent state/context, a two-second rolling buffer, 0.5 VAD threshold, 1,500 ms speech gate, RMS quiet/clipping checks and a speech-versus-nonspeech RMS SNR heuristic. | All-speech/noisy channel SNR and real replay need validation. Shorter than 1.5 s is normally unscorable. |
| Detector | Local ONNX Runtime CPU INT8 wav2vec2/XLS-R artifact, 355,336,130 bytes, SHA256 `7af799e8443c3d030bb3ef644ffc6e74f5b6fddcd6a4286ee9abe9e828cb762e`. Input is finite mono float PCM with per-window mean/variance normalization, 400–64,000 samples and attention mask. Two-class softmax uses fake index 1. | Scores are uncalibrated. The original fine-tuning data and disjointness from proposed tests are not proved. ONNX export parity with the unavailable original weights is unverified. |
| Policy and evidence | 0.40 ELEVATED, 0.75 HIGH; EMA alpha 0.3 with immediate raw HIGH. Each evaluation is persisted and the session points to the latest. Stream TTL 5 s, file TTL 120 s, checked with database time. File upload accepts only uncompressed mono 16 kHz 16-bit PCM WAV, at most 30 s/960,044 bytes, and retains any HIGH in the file. | A later live LOW can replace HIGH as latest evidence. The saved model/profile are not rechecked against current configuration; cached model readiness is a startup/warmup signal, not a continuous health probe. |
| Action security | Sessions own actions by hashed bearer; immutable validated amount/recipient payload binds a simulated transfer. PENDING -> VERIFIED -> COMPLETED; BLOCKED/EXPIRED terminal. The six-digit code is HMAC hashed, lasts 60 s, has three attempts; approval is hashed, action bound, single use and lasts 60 s. Completion locks rows and audits in the same transaction. | A later LOW or source replacement can leave an older pending/verified action eligible; S02 addresses this. Local verifier inbox demonstrates a separate role, not independent banking identity. |
| Database and failure | PostgreSQL `init.sql` plus additive `config/migrations/001_protected_actions.sql`; startup disconnects interrupted audio, preserving action history. `/readyz` checks database, schema, models and verifier. Audit insert failure rolls back the action. | Restart, stream failure, audit failure and overload were exercised in historical B04/B05 receipts, but final source needs rerun. |
| Runtime | Python 3.11 Docker, FastAPI, SQLAlchemy, ONNX Runtime and native JS. Current demo container readiness was HTTP 200. Idle backend snapshot: 794.5 MiB; PostgreSQL: 36.69 MiB. Host is i5-13450HX, 31.7 GiB RAM, RTX 3050 6 GiB; deployed inference is CPU. | Idle memory is not peak memory or a minimum hardware requirement. Dependency versions are lower-bounded, not pinned. No safe `.dockerignore`; R01 remains open. |

## Paper to implementation mapping

| Supplied paper | Relevant result or caution | Current implementation and next evidence |
|---|---|
| Guo et al., [WavLM multi-fusion attentive pooling](<../../reasearch papers/2312.08089v2.pdf>) | Layer/time pooling is a plausible lightweight head. The paper reports frozen WavLM large EER 5.79%, distinct from fine-tuned results. | No WavLM head is deployed. Stage 0 must evaluate the current detector before any frozen-head experiment. Four-second padded lab inputs do not validate the two-second stream. |
| Müller et al., [cross-dataset generalization](<../../reasearch papers/2203.16263v5.pdf>) | Low in-domain EER can become poor in-the-wild EER; duration and preprocessing alter comparisons. | The existing 40 English clips cannot prove unseen-generator or Indian-language performance. Group sources and test 0.5/1/2/4 s and channel shift. |
| Zhong et al., [boundary-aware partial spoofing](<../../reasearch papers/zhong24_interspeech.pdf>) | Frame/boundary localization is a separately supervised task with interval labels. | Retained HIGH and a genuine–synthetic–genuine test are prevention checks, not validated boundary localization. |
| Sharma et al., [IndicSynth](<../../reasearch papers/2025.acl-long.1070.pdf>) | Synthetic Hindi/Marathi/Punjabi and source/target speaker ancestry are useful; paper totals and current hosting counts differ by 123,246 clips. | No IndicSynth data are acquired. Verify actual metadata and licenses, then keep source and target lineage together. No Hinglish claim follows from this corpus. |
| Channing et al., [explainability](<../../reasearch papers/2410.07436v1.pdf>) | Occlusion can be confounded by padding/loudness; cross-domain scores differ from in-domain scores. | Existing reason codes explain deterministic gates, not acoustic origin. Do not claim heatmaps, generator attribution or exact manipulated intervals. |
| Li et al., [survey](<../../reasearch papers/2404.13914v2.pdf>) | Cross-dataset shift, silence shortcuts, dataset ancestry and fixed-input artifacts require explicit testing. | Keep VAD gating and source-aware splits; changing silence handling needs validation. Mean-plus-standard-deviation pooling is a small Stage 1 option. |
| Zhang et al., [survey](<../../reasearch papers/sensors-25-01989-v2.pdf>) | Accuracy alone hides imbalance; codecs, accents and deployment resources matter. Published headline model numbers use differing protocols. | Report fixed-FPR recall, EER, coverage and per-language/channel results; measure the full local pipeline. The detector has no validated fairness or calibrated-probability claim. |

## Resulting change and remaining evidence

S02 now uses numbered 200 ms PCM16 WebSocket frames (`pcm16-seq-v1`), server-owned receipt/cadence checks, a 1.5 s maximum lag and bounded browser buffering. A 600 ms detector cadence brought one 4.8 s file to 2.11 s of local pipeline work; reused display scores do not refresh stored evidence. HIGH, source replacement, disconnect and backend restart terminally block unfinished actions with transactional audit. Evidence is rejected if its saved model/profile differs from the currently loaded pipeline. The legacy unsequenced stream is rejected for protected-action use; the WebSocket route and session authentication remain the same. The final isolated image passed 19/19 API checks, 5/5 hard-restart checks and a 150-frame short stream. An earlier S02 image passed a 2,999-frame/600-second stream and headless fake-device Chrome with WAV fallback. Exact commands, image and source hashes are in the [S02 receipt](s02-2026-09-24.md). The final-image 10-minute stream and physical microphone are separate gates.

Live evidence also requires the current generation in the single serving process's connection registry. That prevents a transient disconnect-audit failure from leaving a stale `LIVE` database row usable. The configured single-worker demo supports this; another worker would deny the action, so multi-worker throughput is not claimed.

Jev now enters only as optional metadata-based decision support after hard gates. The 20-fixture rule suite had zero unsafe downgrades; there is no live Jev key or service measurement. The [Stage 0 receipt](stage0-2026-09-24.md) shows the deployed detector misses the frozen performance targets on a small English regression set. A new SSL model, threshold, explanation display or advisory Jev action effect requires representative disjoint validation and the existing plan’s freeze gates. No four-language corpus, independent physical-microphone rehearsal or untouched final test is available yet.
