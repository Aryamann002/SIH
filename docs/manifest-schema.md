# Audio manifest contract

One UTF-8 CSV row represents one clip. Run `python scripts/validate_manifest.py <corpus>/manifest.csv --heldout-generator <family>` before fitting, selecting a threshold or evaluating. Paths are relative to the manifest directory and cannot escape it. The validator reads local files, verifies SHA256, checks WAV sample rate/duration and duplicate PCM, and rejects cross-split speaker, original-recording, transcript and conversion-voice IDs. It performs no download and writes nothing. Other codecs have only declared metadata checked; probe/decode them separately before training.

The existing detector evaluator accepts this schema with `python scripts/evaluate_audio.py <corpus>/manifest.csv --heldout-generator <family> --output docs/evaluation-output/<run-name>`. It validates the full manifest, then evaluates only validation/test rows through the deployed WAV upload pipeline. Put compatible mono 16 kHz PCM16 WAV files in those splits; other formats are rejected by that pipeline. The evaluator reports available language, generator, channel, replay-status and attack-type slices. A slice with one class has no ROC-AUC/EER. This command is for a properly frozen manifest; do not repeatedly run it on an intended untouched final test during model/threshold selection.

Required columns are `clip_id`, `file_path`, `sha256`, `label`, `language`, `speaker_id`, `source_dataset`, `source_recording_id`, `transcript_id`, `generator_family`, `generator_model`, `attack_type`, `genuine_or_synthetic`, `duration`, `sample_rate`, `codec`, `channel`, `replay_status`, `augmentation_parent`, `consent_or_license`, `split`, `source_speaker_id`, and `target_speaker_id`.

Use `label=genuine` with `genuine_or_synthetic=genuine`, or `label=spoof` with `genuine_or_synthetic=synthetic`. Genuine clips use `generator_family=none` and `generator_model=none`; synthetic clips require an identified family and model. `split` is `train`, `validation` or `test`. `duration` is seconds; `sample_rate` is Hz. `augmentation_parent` is blank for an original, or a `clip_id` in the same training split. Augmented derivatives cannot enter validation/test. The chosen held-out family must appear only in synthetic test rows and be absent from train/validation. Every split must contain both classes.

The IDs must be globally canonical across imported datasets. `speaker_id` names the voice actually heard; `source_speaker_id` names the source voice for conversion; `target_speaker_id` names the target voice. Leave conversion IDs blank when genuinely inapplicable. `source_recording_id` ties all segments, restorations, channel versions and genuine/synthetic derivatives to the same original. `transcript_id` identifies a prompt or canonical utterance; assign a unique recording-scoped ID for untranscribed spontaneous speech. Reused public prompts across corpora may collapse many rows into one split; that is a conservative warning requiring lineage review. Never invent independent IDs for records known to share an original. If a required lineage value is unknown, quarantine that clip rather than marking it “unknown” in a scored split.

The validator catches declared-lineage leakage. It cannot prove that two files from different datasets are independent when metadata conceal their common speaker, text, source audio or pretrained-model ancestry. Before a final split, compare source hashes/fingerprints and dataset release metadata, especially IndicSynth–IndicSUPERB, IndicVoices–IndicVoices-R, ASVspoof–PartialSpoof and LJSpeech-derived corpora. Manual review and a signed manifest version are still required. A passing validator is not an accuracy result.
